# 04 · Proposta de Valor

## Para os Pais

**Promessa central:** *"O teu pediatra de confiança, à distância de uma mensagem — seguro, organizado e sem ir à urgência por tudo."*

| Valor | Como se concretiza |
|---|---|
| **Acesso rápido e fiável** | Consulta por mensagem com SLA visível; resposta de pediatra verificado |
| **Tranquilidade** | Saber se é "vigiar em casa" ou "ir à urgência"; triagem de sinais de alarme com encaminhamento SNS 24 |
| **Confiança** | Só pediatras com cédula validada; avaliações verificadas; continuidade com o "seu" pediatra |
| **Organização** | Arquivo clínico por criança: vacinas, alergias, medicação, exames, relatórios, crescimento/percentis |
| **Conveniência** | Renovação de receita, follow-up, segunda opinião, vídeo agendado — sem sala de espera |
| **Privacidade** | Dados de saúde do filho protegidos (RGPD), não num WhatsApp pessoal |
| **Transparência** | Preço, âmbito e tempo de resposta **antes** de pagar; fatura emitida |
| **Poupança** | Subscrição familiar com pacotes de mensagens e descontos |

**Momentos "aha":**
1. Enviar foto da erupção às 22h e ter resposta clara do pediatra antes de dormir.
2. Ter, num só sítio, o boletim de vacinas e a curva de crescimento dos dois filhos.
3. Renovar a receita do inalador sem marcar consulta presencial.

## Para os Pediatras

**Promessa central:** *"Sê pago pelo trabalho que já fazes — com regras, proteção e faturação tratada."*

| Valor | Como se concretiza |
|---|---|
| **Monetização do trabalho informal** | Cada mensagem/consulta tem preço definido pelo médico |
| **Controlo total** | Define preços por tipo de consulta, horários, SLA, âmbito, indisponibilidades |
| **Proteção jurídica e clínica** | Âmbito explícito, consentimentos, registo defensável, avisos de não-emergência |
| **Separação pro/pessoal** | Fim do WhatsApp pessoal para clínica; canal profissional compliant |
| **Faturação resolvida** | Fatura certificada AT emitida automaticamente; sem trabalho contabilístico manual |
| **Pagamento simples e rápido** | Split automático; dashboard financeiro; payouts previsíveis |
| **Captação e reputação** | Marketplace, perfil público, avaliações verificadas, destaque |
| **Eficiência clínica** | Resumos automáticos da conversa, histórico organizado por criança/episódio, notas |
| **Flexibilidade** | Trabalha quando quer; modo assíncrono encaixa entre consultas presenciais |

**Anti-objeções (desenhar o produto para responder):**
- *"Não quero estar disponível sempre."* → SLA e horários configuráveis; modo indisponível; consultas assíncronas com prazo.
- *"E a minha responsabilidade?"* → âmbito limitado, consentimentos, encaminhamento de urgências, seguro de responsabilidade profissional (a clarificar — ver doc 13).
- *"A comissão compensa?"* → faturação + pagamentos + captação de novos pacientes + zero overhead administrativo.
- *"É só mais um WhatsApp?"* → não: registo clínico, faturação, proteção, pagamento garantido (pré-pago).

## Proposta de valor para a Plataforma (defensabilidade)

- **Efeitos de rede locais**: mais pediatras verificados → mais pais → mais pediatras.
- **Lock-in saudável**: arquivo clínico familiar acumulado + relação com o pediatra de confiança.
- **Barreiras de compliance**: faturação certificada + RGPD + verificação são difíceis de replicar por um concorrente "WhatsApp".
- **Dados (agregados/anonimizados)**: insights operacionais (tempo de resposta, satisfação) — nunca uso clínico secundário sem base legal.
